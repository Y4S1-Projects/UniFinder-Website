Research Domain

Background / Literature Survey

  • ~350,000 A/L candidates annually, but only ~44,000 state university seats available. 300,000+ seek alternatives without structured support.
  • Living costs have risen ~15% in 5 years; graduates increasingly face labour-market mismatches.
  • Existing platforms:
    • CareerMe: Psychometric only, no funding linkages.
    • PickACourse: 300+ institutes listed but lacks AI matching based on specific student profiles.
    • Coursenet / MOE Portals: Static portals acting as mere directories.
  • Missing elements: None offer fraud detection, explainable AI, centralized local scholarship matching, or fully integrated academic-financial-career guidance.

Methodology by Component

Degree Recommendation System (Kaweeshwara — IT22641960)

Sub-problem & Goals

District-based Z-score cutoffs vary annually; strict UGC eligibility rules; lack of personalized interest-aligned guidance; static filtering without explainability.

Core Solution Approach
  • Eligibility Enforcement: Applies UGC rules strictly via Rule-based AI.
  • Semantic Interest Matching: Pre-trained Sentence-BERT model to understand student interests over text input.
  • Hybrid Ranking Mechanism: Combines eligibility status + interest similarity.
  • Explainable Decision Flow: Each recommendation includes plain-language explanations.

Student Budget Optimizer (Dilshan — IT22347862)

An AI-driven financial intelligence system providing predictive budgeting and localized savings strategies for Sri Lankan university students.

Research Gap Addressed
  • Currency/Location Gap: Existing apps ignore local costs in districts like Kandy or Jaffna.
  • Estimation Gap: 62% of students cannot estimate monthly expenses accurately.
  • Action Gap: Traditional tools lack actionable LKR-specific advice.
Solution Architecture
  • Rule-Based Engine: 130,000+ local price records evaluated.
  • Machine Learning: Gradient Boosting (86.89% accuracy) for predictions; Logistic Regression for financial risk.
  • Gen-AI: Gemini 2.0 Flash for conversational budget coaching.

Impact: Identifies LKR 3,000–8,000 avg. monthly savings.

Scholarship & Financial Aid Matcher (Hettiarachchi — IT22627650)

Problem & Solution

Information is scattered. Manual searching leads to missed opportunities. No centralized eligibility-based system exists. The system collects academic/financial details, automatically filters/matches opportunities, and ranks them with clear eligibility explanations.

Technology & Architecture

Built with React, Node.js, Python (FastAPI), Scikit-learn, and Selenium. Architecture integrates a REST API with a FastAPI ML Service using TF-IDF + KNN Similarity alongside a Rule-based Eligibility Engine.

Hybrid Model Approach
40% Content-based
35% Collaborative
25% Knowledge-based
Expected Outcomes: 85%+ recommendation accuracy | 20% increase in scholarship success rates | 70% reduction in search time.

Career Outcome Predictor (Siriwardana — IT22627100)

Career Pathway, Skill Gap & Job Match Recommender for IT students.

Core Functionality
  • Job-role suitability analysis and skill gap identification.
  • Uses predefined static career ladders validated by real job market data.
  • TF-IDF–based role–skill profiles reflecting industry expectations.
User Experience & Design
  • Clear visual representations of missing skills for target roles.
  • Explainability-first design matching academic rigor.
  • Decoupled architecture: Research execution vs Runtime APIs.
